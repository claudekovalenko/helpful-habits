# Helpful Habits

A small habit tracker in one file (`index.html`). Open it in any browser; no install needed.

## Habits tracked

| Habit | How often |
|---|---|
| Work out at 9am | Daily |
| 30 min extra work at home | Daily |
| Give food that helps out | 1–2 times a week |
| Knock out a seminary quick win | Daily |
| Review vocab & concepts (a little) | Daily (5 cards) |

## Tabs

- **Today**: check off habits, see streaks, and see the next seminary quick win.
- **Seminary**: add assignments with points and estimated minutes. They're sorted by points per minute, so the low-hanging fruit is at the top.
- **Vocab**: add words and concepts, then do a 5-card review. Finishing the review checks off the habit for the day.
- **Progress**: a 4-week calendar, per-habit stats, seminary points earned, and export/import for backups.

Data is saved in your browser's local storage. Use **Export** now and then to keep a backup.

To change the habits, edit the `HABITS` list near the top of the `<script>` in `index.html`.
